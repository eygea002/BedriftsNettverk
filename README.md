Bedriftsnettverk – Cisco Packet Tracer
Dette prosjektet handler om å planlegge, bygge, konfigurere og teste et bedriftsnettverk i Cisco Packet Tracer.

Nettverket består av flere avdelinger med egne rutere, switcher og PC-er, samt et sentralt servernettverk.

Målet med prosjektet:

Planlegge fysisk og logisk nettverkstopologi.
Konfigurere IP-adresser og DHCP.
Sette opp routing mellom avdelingene.
Konfigurere DNS- og HTTP-server.
Teste nettverket med ping, ipconfig og tracert.
Dokumentere konfigurasjon, testing og feilsøking.
Verktøy: Cisco Packet Tracer.

Resultat: Et fungerende bedriftsnettverk der avdelingene kan kommunisere med hverandre og få tilgang til sentrale nettverkstjenester.
